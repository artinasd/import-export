# راه تجارت — Import / Export Corporate Website

Premium Persian RTL corporate website demo for an international sourcing, import/export and customs consultancy business.

## Current scope

This repository currently contains the UI-first demo homepage. Backend, MySQL, authentication, CMS, inquiry processing and production deployment are intentionally deferred until the demo is approved.

## Stack

- Next.js App Router
- React
- JavaScript
- Tailwind CSS
- Lucide React
- npm

## Run locally

```powershell
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Design direction

Persian-first, RTL, editorial, minimalist and premium. The interface deliberately avoids conventional corporate-template layouts and uses strong typography, restrained color, generous whitespace and subtle interaction patterns.
